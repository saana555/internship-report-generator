# Internship Report Generator - GPTC Kalamassery

A client-side HTML/CSS/JavaScript internship report generator.

## Run
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In Settings -> Pages, choose Deploy from branch.
4. Select the main branch and root folder.
5. GitHub will give you a public URL.

No server/database is required. Student data is saved in each student's browser using localStorage.
